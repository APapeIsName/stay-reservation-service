# 발제 문서 동결

## Rule
`docs/curriculum/*.md` 는 부트캠프 주차별 발제를 **원문 그대로** 보존한 동결 파일이다. 어떤 편집(요약/번역/오타수정/도메인 치환)도 금지.

## Why
발제 원문은 과제 기준점이자 면접에서 인용 가능한 원자료. 변형되면 신뢰성·정합성 손상.

## How to apply
- 파일은 `chmod 444` 읽기 전용으로 동결 (현재 `round-1.md` 동결됨)
- 새 주차 발제도 같은 규칙: `docs/curriculum/round-N.md` 원문 저장 → `chmod 444`
- 내용 변경이 필요해 보이면 사용자에게 먼저 확인 (rule 자체 갱신 검토)
- 발제와 다른 해석·결정·재구성은 별도 작업 문서(`docs/round-N/*.md`) 에 기록
- **위반 신호**: 발제 파일 수정 시도 / 발제 본문을 다른 위치에 변형 복제
